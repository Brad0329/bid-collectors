## 1. 무엇이 바뀌었나
- **버전 · 커밋 · Phase**: v1.2.5 · `a5ceaa0`(구현) — 앞선 문서 커밋 `27864cf`(원칙 기록)·`865484d`(Phase 006 발급)·`f117bd5`(bidwatch 경계 원칙) · `work_log/plan.md` Phase 006.
- **계약**(`Notice`·`CollectResult`·시그니처·`bid_no` 형식·공개 export): **불변** — patch. 결정 기록 `docs/CONTRACT.md` 변경 이력 2026-09-25 행.
- **동작 1 — `Notice.extra`가 응답 원문 전부로 바뀜(원칙 ① "숨기지도 더하지도 않는다")**
  - 모든 API 수집기(나라장터 입찰공고·낙찰·계약·사전규격, 기업마당, K-Startup, 중소벤처기업부, 보조금24, 알리오)의 `extra`가
    **응답 항목의 비어 있지 않은 필드 전부를 원래 이름 그대로** 담는다. 표준 필드로 옮긴 값(공고번호·제목·날짜·예산 등)도 원문 그대로 다시 들어 있다.
  - **종전 영어 별칭 키는 더 이상 오지 않는다** — 나라장터 12개(`est_price`·`budget`·`bid_method`·`contract_method`·`award_method`·`contact`·
    `contact_email`·`tech_eval_ratio`·`price_eval_ratio`·`bid_qual`·`open_date`·`bid_type`), K-Startup 8개, 기업마당 6개, 그 밖의 수집기 키 전부.
    요청 문맥 `bid_type`(용역/물품/공사)·`data_type`(낙찰/계약/사전규격)은 응답에 없는 값이라 뺐다 — `bid_no` 접두사(`용역-`·`낙찰-용역-`)에 있다.
  - 값 규칙: JSON은 값 타입·중첩 그대로(`pbanc_sn`은 int, 조회수는 int) / XML(나라장터·중소벤처)은 태그 → 텍스트, **같은 태그가 2개 이상이면 list**
    (중소벤처 `fileName`·`fileUrl`), 자식이 있는 태그는 dict / 0·False는 값, None·빈 문자열·공백만은 뺀다 / **HTML도 원문 그대로**
    (종전엔 K-Startup `aply_trgt_ctnt` 등에 clean_html을 걸었다 — 표시용 정리는 BidWatch 몫).
  - 크기: 나라장터 항목당 40~140키(2026-09-25 실측 용역 113·물품 101·공사 143 태그 중 채워진 것), K-Startup `pbanc_ctnt`·기업마당 `bsnsSumryCn`·
    보조금24 `지원내용`은 본문 HTML 전체가 extra에 들어간다 → JSONB 행 크기가 커진다(결함 아님, 운영 메모).
  - 알리오는 종전 `extra=None`이었다 → 이제 dict(`seq`·`rtitle`·`pname`·`bdate`·`bidInfoEndDt`·`cdNo` 등).
- **동작 2 — 나라장터 확장 3메서드(A)**: `collect_awards`·`collect_contracts`·`collect_pre_specs`가 ID(낙찰 `bidNtceNo`·계약 `dcsnCntrctNo`|`untyCntrctNo`·
  사전규격 `bfSpecRgstNo`|`refNo`)나 제목이 없는 항목을 건너뛴다. 종전엔 `낙찰-용역-`처럼 접두사만으로 합쳐져 서로 다른 공고가 1건이 됐다.
  반환형이 list라 errors 채널이 없어 **경고 로그**(`bid_collectors` 로거, "항목 파싱 예외로 N건 건너뜀 — …")만 남는다. 결과 건수가 종전보다 줄 수 있다(가짜 1건 소멸).
- **동작 3 — 항목 하나의 이상이 결과를 지우지 않음(B)**: 기업마당 `reqstBeginEndDe`·보조금24 `소관기관명` 같은 **선택 필드가 null인 공고가 이제 살아남는다**
  (종전엔 "TypeError 1건"·"ValidationError: organization 1건"으로 건너뛰거나, 기업마당은 `items[-3:]` 판정에서 예외가 나면 앞 페이지까지 0건).
  → errors의 그 사유가 줄고 `is_partial` 빈도가 낮아진다. K-Startup은 제목이 문자열이 아니면 "ValidationError: title" 사유로 건너뛴다(종전 TypeError).
- **`docs/interface.md` diff**(bidwatch 쪽 같은 파일에 반영): 머리말 2줄(변경은 bid-collectors에서, bidwatch 반영은 handover) · §1 `extra` 블록 주석 6줄과
  '필드 규칙' 표의 `extra` 행 · §6 "v1.2.5 기준". **이 저장소의 `docs/interface.md`로 통째 교체**하면 된다(다른 절은 동일).
