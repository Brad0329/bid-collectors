## 2. 호출 한도 [실]
- data.go.kr 한도는 **오퍼레이션(상세기능)별**이다 — 응답 헤더 `x-ratelimit-remaining`이 오퍼레이션마다 따로 준다(d2b 국내목록 91·시설목록 98·상세 각 99, 나라장터 물품 953·공사 960).
  요청서의 "1,000회를 나라장터 등과 공유" 전제는 틀렸다 — 기관 수집기는 기존 수집기 한도를 잠식하지 않는다.
- d2b 개발계정은 오퍼레이션당 **100/일** — 목록 1회/일은 여유, 상세를 전 공고에 부르면(하루 ~130) 초과.

## 3. 기관별 실측 상세와 함정

### LH (호출 28회 중 일부, 14일 139건·90일 1,018건·365일 3,791건)
- XML **EUC-KR** — 바이트 그대로 lxml에 넘긴다(UTF-8 재인코딩 시 파싱 실패). `_type=json` 무시.
- 필드 170개. 공고번호 `bidNum`(7자리) — 공고 1건 = 1행, 정정·취소 시 **같은 행의 `bidDegree` 00→01과 공고일(`tndrbidRegDt`)이 정정일로 바뀐다** → bid_no는 `bidNum` 하나, 차수는 extra. 90일 중복 0.
- 날짜 파라미터 = 공고일(`tndrbidRegDt`). 빈 결과 = `resultCode 03 NODATA`(날짜 역전도 03 → 호출 전 범위 검사). 하이픈 날짜·누락 = 11.
- 원문 링크 필드 없음 — 알리오 refrUrl은 공고 구분(`cstrtnJobGbNm`)별 경로(시설공사 Construct·지급자재 ctrctgds·용역 srvcs)로 조립돼 있다 [실 15건]. 물품 경로 미확인.
- `bidProgrsStatus`(진행·개찰·유찰)는 현재 상태라 바뀐다.

### 국방 d2b (d2b 20회 + 나라장터 대조 5회)

| 국내경쟁 `getDmstcCmpetBidPblancList` | 111 (인자 없이 174 = 개찰 전 전량) | pblancNo+pblancOdr | 공고일 pblancDate |

- 목록은 **개찰 전 공고 스냅숏**(국내 opengDt 최소 = 9/28) → 날짜 조건 없이 전량 받는 방식이 지연·누락에 가장 안전. numOfRows 1000 한 페이지(100이면 100건 + totalCount 174 — 조용한 절단 아님).
- 같은 pblancNo가 차수별 여러 행(정정·재공고·취소 = `pblancSe`) → bid_no에 차수 포함.
- `g2bPblancNo`는 나라장터 번호가 **아니다** — d2b 필드 이어 붙인 값(100% 일치).
- 함정: 날짜 형식 오류·필수 누락도 `00` + 0건 · JSON `dcsNo` int/str 혼재(str 통일) · 문자열 끝 공백 · 원문 링크·첨부 필드 없음(12개 오퍼레이션 전부).

### 가스공사 (365일 1,011건)
- XML UTF-8, 필드 14개. 공고번호 `NOTICE_CODE` **10자리**(1차 조사의 13자리는 오기), `bid_code`·`round`는 응답에 없다(알리오 refrUrl은 001/01).
  번호 앞 8자리는 공고일이 아니다(차이 0~38일).
- 날짜 파라미터 = 공고일(`NOTICE_DT`). 취소는 공고일 그대로 `CANCEL_YN=취소`로만 표시 → 14일 창 권고.
- 함정: 날짜 누락·파라미터 이름 오류·역전 모두 `00` + 0건 · 마지막 페이지 초과 시 `pageNo` 응답값이 틀림 · 낙찰 필드 5개 전부 빈 값.

### 수자원 (47회, 두 달 636행)
- 날짜 필터는 `searchDt=YYYYMM`(공고일 기준 월) 하나뿐 → 매번 그 달 전체 받고 공고일로 거른다. 월초는 전월 포함.
- **응답 약 51KB 초과 시 HTTP 200 + 본문 0바이트**(에러·건수 없음) → `numOfRows=100` 페이지 + 빈 본문을 실패로 보고.
- 에러와 0건 구분 불가: `searchDt` 누락·미래 월·범위 밖 페이지 = `00`/0건/`items ""`. 형식 오류는 JSON 빈 본문, XML `99 ORA-…`.
- JSON: 1건이면 `items.item`이 dict, 0건이면 `items == ""`. 공고일 `tndrPblancDe` 정수, 마감일 절반 `"-"`, 금액 `tndrPlnprc` 0 = 미공개(용역 68/142).
- 공고번호 `tndrPbanno`(영문 1 + 숫자 10, B3 공사·B5 용역·B1 물품/내자), 차수 필드 없음 — 재공고는 새 번호 + 제목 `(재공고)`. **취소 공고는 API에서 빠진다.**
- 사전규격·발주계획은 **공고번호 필드가 없다**(bid_no 설계 필요). 입찰결과 `rstList`는 개찰일 기준, 낙찰예정이면 낙찰 키 자체 없음.
