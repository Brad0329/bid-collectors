## 2. 공통 사항
- **활용신청 필요(사용자)**: 15101635·15101628·15102588(수자원) · 15159012(LH) · 15158416(d2b) · 15157366(가스) · 15125329·15084607·15084782(발전사, 한전 포털로 대체 시 불필요).
  신청 후 확인할 것: 필드 실제 존재·totalCount·numOfRows 상한·1일 건수·공고번호 값이 알리오 키와 같은지.
- **호출 한도 전제 불일치**: 요청서는 "data.go.kr 1,000회를 나라장터 등과 공유"라 했으나 data.go.kr 한도는 **활용신청한 API별로** 표시된다(d2b 100, LH 1,000, 수자원·가스 10,000) [문]. 합산 여부 미검증.
- **알리오 제목 번호 정규식 초안**(알리오 3일 946건 [실]): 한전·발전사 `^\[([BEG]\d{9})\]` · 수자원 `^\[([A-Z]\d{10})\]` · 한수원 `\[([A-Z]\d{2}[A-Z0-9]\d{6})\]`(말머리 `[정정공고]` 허용, 다른 형식 7/66 섞임) ·
  LH refrUrl `bidNum=(\d{7})&bidDegree=(\d{2})` · 가스 refrUrl `notice_code=(\d{10})`. 대괄호 번호 = 원천 공고번호는 수자원만 확인.

## 3. 조사 중 발견(별건)
- 알리오 `collect(days=7)`가 기본 `max_pages`(150)에서 절단(1,498건, is_partial로 보고됨) [실] — 3일은 97페이지로 안 잘림. BidWatch 정기 수집 주기(days)와 맞는지 확인 필요.
- 알리오 LH `refrUrl`이 `https://` 없이 온다(`ebid.lh.or.kr/...`) [실] — 링크로 쓰면 상대 경로. 원문 전달 원칙상 패키지는 그대로 두고 표시 쪽(BidWatch)이 보정.
- 알리오 가스공사 refrUrl 11건 중 4건이 `&amp;amp;` 이중 이스케이프 [실].
